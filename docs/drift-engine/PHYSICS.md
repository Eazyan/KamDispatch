# Физика и приближения

ФАКТ по коду: запас в кг/м²; площадь открытой ячейки в м²; шаг по времени в секундах.
Начальный рыхлый запас задан явно, неизвестное не заменяется нулём. Осадки кг/м²/ч.
SnowState переносит массу через общую грань с ограничением доступной донорской массы.
Здания маскируются, границы закрыты. Баланс: M = M0 + осадки + вход - выход - вывоз - потери.
В этом режиме старение выключено; нет термодинамики, сублимации и уплотнения.

По умолчанию плотность сценарного снега 200 кг/м³. Поверхность = DSM + масса/плотность.
Экспозиция = clip(1 + 2 * направленный уклон, 0.25, 2). При изменении поверхности
>= feedback_m экспозиция пересчитывается. Направление потока не поворачивается.
Это не решение уравнений воздуха; коэффициент 2 не калиброван. Транспорт использует
существующую пороговую сальтационную ёмкость SnowState, не перенос взвешенных частиц.
Доступный снег ограничивает перенос даже без осадков. Нет ветрового следа зданий.
Закрытая граница вызывает сценарное накопление у края; это не прогноз городской границы.

Отдельный simpleFoam решает стационарный RANS воздуха на 3D-сетке с k-epsilon;
поля p кинематические, а не давление в Па. Здания представлены ступенчатой маской ячеек.
Пока не решены концентрация снега, обмен с ложем, движение снежного mesh и повторный
CFD после изменения сугроба. Обновление уклонной поправки не считается этим испытанием.
Источник: drift_engine.py, snow_state.py, cfd/run_cfd.py и реальные журналы results.
Статус: численно проверено; полевая точность unknown. Необходимо проверить перенос
параметров между масштабами, порог отрыва и фактическую рыхлость/плотность.
