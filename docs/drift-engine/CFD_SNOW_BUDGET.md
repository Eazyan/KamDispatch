# Контракт обмена снегом и полного бюджета

23.11.2026 · Asia/Kamchatka · ФАКТ: подготовительный код DRIFT-003, поверх eb23cbc.
Источник: city-sim/city_sim/cfd_snow_budget.py и tests/test_cfd_snow_budget.py.

`exchange` принимает начальные массы ложа и воздушных ячеек (kg), отображение
каждой обменной грани на оба донора и запрошенные интегральные erosion/deposition
(kg за шаг). Сначала суммирует запросы всех граней одного донора; затем
пропорционально ограничивает их его начальным запасом. Полученная на этом шаге
масса доступна для обратного переноса только на следующем. Входы не изменяются.
При исчерпании оставляется запас порядка машинного округления; масса остаётся
на доноре, не исчезает. Отрицательные/NaN/Inf входы, неверные индексы, переполнение
и отрицательные результаты отклоняются. Исправления CFD концентраций обрезанием нет.

`audit` проверяет:

```
residual = bed_final + air_final + boundary_out + explicit_loss
           - bed_initial - air_initial - boundary_in
```

Все значения — неотрицательные интегральные kg. Допуск по умолчанию
1e-8 kg + 1e-12 × (bed_initial + air_initial + boundary_in).
Внутренние erosion/deposition не входят в внешние источники/потери.

## Проверено

Пять новых тестов: общие доноры нескольких граней, одновременный обмен,
100 последовательных шагов со случайным завышенным спросом, сохранение исходных
массивов, обнаружение пропущенного граничного потока, некорректные входы и
синтетический обмен на drift-scene-1. Полная suite: 96 tests OK; после последней
проверки результирующих массивов повторены 5 новых tests OK.
Команда из city-sim:

```
python -m unittest city_sim.tests.test_cfd_snow_budget -v
```

## Следующий шаг — ПЛАН

Адаптер обязан получить физические объёмы воздушных ячеек и площади граней
OpenFOAM, перевести концентрацию kg/m³ в kg, интегрировать потоки за dt и передать
ограниченные внутренние источники в временное уравнение. Граничный ledger должен
браться из тех же численных потоков, которыми обновляется поле, с учётом обратного
втекания; отрицательные концентрации должны приводить к диагностике, не clipping.
Затем реальный короткий Kamchatka case, независимый интегральный audit и проверки dt.
Стационарный upstream TEqn.H не содержит ddt: его итерации не являются секундами.

Это контракт и вычислительный контроль, НЕ запущенный CFD snow case, не закон
эрозии/осаждения и не доказательство точности. Синтетические запросы в тестах
не получены из ветра. Новый CFD runtime и feedback сетки здесь не выполнялись.
