# API обращений жителей

FastAPI принимает обращения на том же адресе, что и API мониторинга. Миграция `011_citizen_reports.sql` применяется при запуске. Фотография, текст, координаты и теги сохраняются в PostgreSQL одной транзакцией.

## Приём обращения

`POST /api/v1/citizens/reports` принимает `multipart/form-data`.

| Поле | Формат |
| --- | --- |
| `photo` | Один JPEG или PNG до 5 МиБ и 16 мегапикселей. API сохраняет JPEG без метаданных с длинной стороной до 2048 пикселей. |
| `description` | Текст от 1 до 2000 символов. |
| `latitude` | Широта WGS84 от −90 до 90. |
| `longitude` | Долгота WGS84 от −180 до 180. |
| `tags` | До четырёх необязательных повторяющихся полей. Допустимы `снег`, `дождь`, `пробка`, `сугроб`. Дубликаты удаляются. |

Клиент получает координаты из геолокации устройства, выбранной точки или результата геокодирования вручную введённого адреса. Пользователь может проверить найденную точку на карте перед отправкой. Сервер определяет район по координатам. Геокодер и интерфейс ввода находятся за пределами этого API.

```bash
curl -F photo=@snow.jpg \
  -F 'description=Сугроб закрывает проход' \
  -F latitude=53.02 -F longitude=158.65 \
  -F tags=снег -F tags=сугроб \
  http://localhost:8080/api/v1/citizens/reports
```

Успешный ответ имеет статус `201` и содержит поля `id`, `description`, `latitude`, `longitude`, `district_id`, `district`, `tags`, `suggested_tags`, `created_at` и `photo_url`. Поле `suggested_tags` содержит автоматически определённые зимние теги. Некорректные поля дают `422`, превышение лимита загрузки даёт `413`, неподдерживаемое или повреждённое фото даёт `415`.

## Чтение

| Маршрут | Ответ |
| --- | --- |
| `GET /api/v1/citizens/districts` | Массив вариантов фильтра с полями `id` и `name`. |
| `GET /api/v1/citizens/reports` | Обращения с полями как у ответа `201`. Необязательные фильтры: `district` (идентификатор), `start` и `end` (ISO 8601 со смещением или `Z`), `id` (UUID записи). Без фильтров возвращаются последние обращения по всем районам. Период применяется к времени создания, начало включается, конец исключается. Новые записи идут первыми. |
| `GET /api/v1/citizens/reports/{id}/photo` | Сохранённое фото с типом `image/jpeg`. |

Список возвращается как `{"items":[...],"next_offset":null}`. Передайте `limit` от 1 до 100 (по умолчанию 50) и `offset` (по умолчанию 0). Для следующей страницы передайте значение `next_offset`, если оно задано.

```bash
curl --get http://localhost:8080/api/v1/citizens/reports \
  --data-urlencode district=unassigned \
  --data-urlencode 'start=2026-11-22T00:00:00+12:00' \
  --data-urlencode 'end=2026-11-23T00:00:00+12:00'
```

В режиме `live` передавайте `Authorization: Bearer <OIDC token>`. Создать обращение может любой пользователь с действительным токеном приложения. Список районов и обращений доступен операторам и наблюдателям. Фото доступно также автору, а для остальных запрос возвращает `404`. Локальные режимы работают без токена. Обращения из разных режимов изолированы.

В панели мониторинга вкладка «Обращения жителей» показывает поступившие записи, фильтры по району и датам, адрес, координаты, теги и фото. Даты фильтра относятся к часовому поясу Камчатки. На экране «Обстановка» последние три записи обновляются каждые 10 секунд в режиме данных сервиса. В `live` действует доступ оператора или наблюдателя.

## Границы районов

По умолчанию API определяет муниципальный район или городской округ по локальному GeoJSON с 14 муниципалитетами Камчатского края. Это снимок границ OpenStreetMap, а не кадастровый набор. Для вычисления района используется попадание координат в полигон, включая границу. Например, точка `53.0196, 158.6478` относится к Петропавловск-Камчатскому городскому округу. Координаты из обращений обрабатываются на сервере. Внешние запросы для определения района не нужны. [Снимок исходных данных](https://github.com/timurkanaz/Russia_geojson_OSM/tree/5af46d6dab9a502713611846892e4185f157dab7) · [© OpenStreetMap contributors, ODbL](https://www.openstreetmap.org/copyright).

Чтобы заменить справочник в Docker Compose, положите GeoJSON в `runtime/citizens/districts.geojson` и задайте в `.env` значение `CITIZEN_DISTRICTS_FILE=/app/runtime/citizens/districts.geojson`. При запуске без Compose укажите путь к файлу в переменной окружения. Файл должен содержать `FeatureCollection` с геометриями `Polygon` или `MultiPolygon` в WGS84. Порядок осей в GeoJSON — `[долгота, широта]`. Для каждого объекта задайте `properties.id` (уникальный стабильный идентификатор из строчных латинских букв, цифр и дефисов) и `properties.name` (название для интерфейса). На общей границе выбирается первый подходящий объект в порядке файла.

Справочник загружается при запуске и применяется к новым обращениям с сайта и из Telegram. При запуске API повторно определяет район для записей текущего режима с `district_id=unassigned`. Ранее назначенные районы сохраняются. Если точка находится вне покрытия, сохраняются `district_id=unassigned` и `district=null`. Такие записи доступны через фильтр `district=unassigned`. Значение `unassigned` зарезервировано.

## Бот и сайт

Форма доступна по адресу `/citizens/` на том же сервере. Она поддерживает загрузку фото, предпросмотр, геолокацию, выбор точки на карте и поиск адреса. В режиме `live` форма запрашивает токен доступа OIDC, полученный во внешней системе входа. Значение передаётся только в заголовке API и не сохраняется в браузерном хранилище.

Два дополнительных поля при отправке необязательны. `address` хранит подпись адреса до 240 символов. `request_id` принимает UUID. Повтор с тем же UUID, автором и режимом возвращает исходное обращение со статусом `201`. Словарь из предыдущей версии заполняет `suggested_tags` при сохранении. Ручные теги остаются в `tags`.

Бот передаёт `X-Citizen-Bot-Key` с внутренним ключом и `X-Telegram-User` с ID автора приватного сообщения. FastAPI принимает такой запрос только с настроенным ключом. Бот скачивает фото у Telegram и передаёт его как multipart. Подтверждённые обращения и фото для просмотра бот получает из API. Через бота доступны `/my`, `/my UUID`, `/report UUID` и `/description UUID`.

| Маршрут | Ответ |
| --- | --- |
| `GET /api/v1/citizens/reports/mine` | Массив обращений автора. Можно указать `limit` (по умолчанию 5) и `before` (UUID последней записи предыдущей страницы). Требуется Telegram или OIDC. |
| `GET /api/v1/citizens/reports/{id}` | Обращение автора. Требуется Telegram или OIDC. |
| `GET /api/v1/citizens/reports/zones?minimum=2` | Ячейки сетки 0,01° текущего режима с полями `latitude_cell`, `longitude_cell`, `count`. Чтобы получить нижнюю границу ячейки, разделите индексы на 100. В режиме `live` требуется доступ оператора или наблюдателя. |
