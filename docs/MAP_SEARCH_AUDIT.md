# Аудит поиска KamDispatch · 24 ноября 2026

Аудит выполнен на `main` `9a1519d`. [PR #20](https://github.com/Eazyan/KamDispatch/pull/20)
добавил библиотеку SQLite-поиска City Sim. [PR #21](https://github.com/Eazyan/KamDispatch/pull/21)
подключил её к карте вместе с частичными OSM-выгрузками. Открытый
[PR #22](https://github.com/Eazyan/KamDispatch/pull/22) меняет транспорт
данных пробок. В нём пять файлов и отсутствуют изменения индекса поиска.

## Причины пропусков

| Слой | Наблюдение | Изменение |
| --- | --- | --- |
| Источник адресов | Выгрузки дорожного графа и 3D-атласа охватывали отдельные участки города | Добавлен срез по границе Петропавловска-Камчатского из [регионального PBF](https://download.geofabrik.de/russia/far-eastern-fed-district.html). [Сборка и контрольные суммы](../monitoring/data/README.md) |
| Разбор запроса | Полный адрес с городом и `74 / 2` терялись, хотя объект был в каталоге | Название улицы и номер сопоставляются отдельно. Поддержаны порядок «номер, улица», опечатка и префикс улицы, неправильная раскладка, дроби, корпуса, строения, владения и литеры. Номер сравнивается точно |
| Нормализация данных | Тип улицы мог уничтожить всю строку «Набережная улица». В снимках встречаются `с1`, `ст1`, адреса через `addr:place` и дроби с обратной косой чертой | Запрос и запись каталога используют одну нормализацию. Проверяется обратное преобразование каждого адреса |
| Скорость и ранжирование | 5 016 служебных названий вида «Участок OSM …» заново добавлялись в SQLite на каждый запрос | Сегмент доступен по явному OSM ID. Статический индекс улиц, мест и страниц строится один раз. Точное совпадение улицы получает приоритет |
| Отображение | По отсутствующему дому трудно отличить пробел карты от прочих причин | Для однозначно найденной улицы виджет показывает линию улицы и подпись «Дом не найден в справочнике». Геометрия дома берётся из адресной точки или контура OSM |

## Проверенные точки входа

| Экран или API | Источники и проверки |
| --- | --- |
| Общий поиск карты, 2D/3D | Геометрия улиц из `graph_v3`, справочник дорог и городской OSM-слой. Для мест используются именованные OSM-объекты. Проверены театр, школа с номером, название улицы с числом, отдельный OSM-сегмент, геометрия и точка дома |
| Камеры | Общий поиск использует каталог и выбранный запуск. В разделе «Камеры» отдельный фильтр работает по видимому набору, принимает слова из нескольких полей, нормализует `ё` и знаки и точно сравнивает числовые токены |
| Автобусы | «Борт» и «маршрут» ищутся по отдельным полям. Результат со свежими серверными координатами можно открыть, даже если список на экране ещё не обновился. Поиск реальных бортовых номеров по-прежнему зависит от данных РНИС |
| Обращения, задания и страницы | Оперативные сущности индексируются для выбранного запуска, отдельно от общего статического каталога. Обращения ограничены 500 последними записями текущего режима. Демо-фильтр сохраняет общедоступные объекты карты и исключает оперативные данные чужого режима |
| Форма жителя | Адреса города доступны через `/api/v1/citizens/address-search`. Интеграционный тест сравнивает координаты с `/api/v1/map/search`. Photon остаётся внешним поиском для запросов вне распознанного городского каталога |
| Telegram и MAX | Один адресный разбор, подтверждение выбранного дома, проверка доставки адреса в API на подставных ответах и сохранение выбора геометки |
| City Sim, Python и CLI | Существующий независимый SQLite-интерфейс и тесты адаптеров. Адаптер JSON учитывает `addr:place`. Пробелы вокруг дроби допустимы. Выгрузки расчётных объектов City Sim остаются самостоятельными источниками |

## Измеренное покрытие

- До изменений развёртываемый код индексировал 4 190 пар «улица — номер». При одинаковом новом парсере старые источники дают 4 208 пар, а добавление городского среза увеличивает каталог до **5 072 пар и 271 адресного названия**. У карты **332 имени улиц/проездов** по всем источникам и **2 181 именованный объект OSM**. Эти числа характеризуют покрытие данных, доля всех существующих зданий неизвестна.
- «Ленинская, 8» находится по адресу OSM way [128672871](https://www.openstreetmap.org/way/128672871). «Ленинская, 4» отсутствует во всех исходных OSM-срезах и в обоих проверенных представлениях реестра домов. Действующая запись с геометрией для № 4 не подтверждена. [ФИАС Онлайн](https://xn--80ap2aj.xn--80asehdb/281e8671-28c3-47c6-8046-93a6b4e7a51e/) · [OpenAddress](https://openaddress.ru/41/41000001000020800)
- В отдельной контрольной выборке есть подтверждённые пробелы. У опубликованного списка из 30 адресных записей Ленинской отсутствуют пять точек `14А`, `14 стр. 1`, `22 стр. 1`, `22 стр. 2`, `64`. У первых 15 номеров Ленинградской из опубликованного адресного перечня отсутствуют `4`, `6`, `7`, `18`, `38`. Выборка построена для диагностики и не представляет весь город. [Список Ленинской](https://xn--80ap2aj.xn--80asehdb/281e8671-28c3-47c6-8046-93a6b4e7a51e/) · [Адресный перечень Ленинградской](https://base.garant.ru/411137234/53f89421bbdaf741eb2d1ecc4ddb4c33/)
- Примеры из нового среза включают `2-я улица Шевченко, 19` и адреса на улицах Авиаторов и Невского. «Камчатский театр драмы» и «школа 5» имеют отдельные результаты с точками на карте.
- На локальном повторе прогретый старый поиск «Ленинская 8» занимал примерно 217 мс. Новый структурированный поиск занимает меньше 1 мс без оперативных слоёв, а три слова названия театра — около 35 мс на прогретом статическом индексе. Подготовка каталога с холодного диска заняла около 2,2 с. Время сети, браузера и PostgreSQL в замере отсутствует.

Для проверки полноты города потребуется актуальный [ГАР ФНС](https://fias-file.nalog.ru/Search)
и источник координат домов либо контуров, который можно включать в сервис на
понятных условиях. Список стран [Overture Addresses](https://docs.overturemaps.org/guides/addresses/)
на момент аудита не включает Россию.

## Проверка изменений

86 серверных тестов прошли на чистой PostgreSQL 16, включая прохождение всех
строк локального каталога и сравнение ответов двух HTTP API. Прошли 26 тестов
библиотеки City Sim, 16 тестов веба и production-сборка TypeScript/Vite.
Отдельный демостенд по HTTP вернул веб, форму, результаты поиска адресов,
точки школы и автобус № 20. Интерактивный браузерный прогон прервался по
тайм-ауту инструмента. Действующее публичное развёртывание в рамках аудита
не обновлялось.
