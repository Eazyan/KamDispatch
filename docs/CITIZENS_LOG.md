## 22 ноября 2026 · единый сервис для формы и Telegram

- Индекс проекта. `monitoring/api.py` обслуживает API и статику. `monitoring/citizens.py` содержит маршруты, обработку фото и операции с обращениями. `monitoring/migrations/` обновляет PostgreSQL при старте. Панель диспетчера собирается из `web/`, форма жителей обслуживается из `resident_site/` по адресу `/citizens/`. `compose.yaml` и `bootstrap.sh` поднимают базу, API, обработчик мониторинга и бота.
- Из `../bot` перенесены интерфейс с Leaflet, поиск по адресу, предпросмотр фото, диалог Telegram, просмотр личной истории, сводка зон и словарь зимних тегов. Бот `monitoring/citizen_bot.py` отправляет файл в API и читает историю и фото через API. Черновики остаются в памяти бота до отправки. Во время работы у формы и бота нет зависимости от SQLite.
- Миграция `012` добавила адрес, предотвращение дублей по UUID запроса в рамках автора и режима, индекс истории. Автоматические теги хранятся отдельно от ручных. Для Telegram используется внутренний ключ; для браузера в `live` сохранена действующая схема OIDC. Сводка зон в `live` доступна сотрудникам. У формы и бота общий лимит загрузки 5 МиБ.
- Исходная папка и SQLite сохранены. Прежние процессы не обнаружены. Исходный SQLite содержит четыре записи, из них три со ссылкой на фото Telegram. `monitoring/citizen_import.py` читает снимок в режиме read-only, сохраняет фото и исходное время в PostgreSQL и пропускает уже перенесённые записи при повторном запуске. Сам снимок пока не переносили. Для получения ранее загруженных фото нужен токен исходного бота и должен быть выбран режим назначения.
- `./bootstrap.sh` создаёт ключ бота в локальной конфигурации, ожидает готовности API и печатает адрес формы. Без `BOT_TOKEN` контейнер бота завершает запуск штатно. Порядок запуска и переноса описан в README.
- Проверки. На чистом PostgreSQL 16 прошли 38 Python-тестов, включая изоляцию истории, повтор запросов, откат импорта и обмен бота с API на подставном Telegram. Сборка и запуск через `./bootstrap.sh` прошли. `/citizens/` ответил HTTP 200, `/healthz` вернул `ready`. `git diff --check`, проверка Bash и синтаксиса JavaScript прошли. Подключение реального Telegram и перенос исходной базы остаются после настройки `BOT_TOKEN`.
- Веб-тесты панели прошли, 8 тестов. Временный контейнер PostgreSQL остановлен. Локальный стек оставлен запущенным.
