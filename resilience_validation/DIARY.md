# Дневник продолжения PR #24

24.11.2026, Камчатка. Новый checkout создан от подтверждённого `main@9a1519d`. Черновик PR #24 оставлен источником первичного baseline. Продолжение меняет backend, тесты, контракт и локальный Compose. Интерфейс в дифф не входит.

- Введены миграция причин checks, статус по точкам OpenWeather, срок актуальности, порог heartbeat и API состояния. Поддержана выдача 503 при старте и работе без PostgreSQL. Публичный фильтр принимает новый контракт и сохраняет тип ошибки базы.
- Пробки классифицируются по времени каждого интервала. Проверена граница TTL. Пропуски не заполняются признаком свободного движения. РНИС оценивается по времени измерения.
- Первая проверка стенда обнаружила, что SQL-паттерн требовал экранирования процента в psycopg. Ошибка устранена. Дополнен автоматический тест чтения статусов из PostgreSQL.
- В первом прогоне 500 клиентов драйвер httpx снижал частоту запросов при почти простаивающих контейнерах. Замеры чтения повторены с aiohttp. Отдельный тест регистрации обращений использовал интервал 60 мс и проверял фактическую запись через SQL.
- Проведены испытания назначения, повторной передачи, параллельных снежных расчётов, источников, каскада и подготовки чистого восстановления. Сценарии с повторной доставкой используют синтетический объект и внутренний API. Мессенджеры не запускались.

Последующие замеры и выводы отражены в [REPORT.md](REPORT.md). Первичный аудит доступен в [PR #24](https://github.com/Eazyan/KamDispatch/pull/24).

Чистая сборка завершилась BLOCKED из-за HTTP 503 при загрузке Debian-пакетов. В PR #26 добавлены экспериментальные материалы и workflow GitHub Actions.
