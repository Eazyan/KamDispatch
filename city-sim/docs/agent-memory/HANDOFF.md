## Что действительно реализовано

city-sim/city_sim/drift_engine.py использует существующий SnowState с закрытым массовым балансом, ограничением снегозапасом, маской зданий и направленной уклонной поправкой экспозиции. Поправка пересчитывается после изменения сценарной снежной поверхности, но это НЕ CFD, НЕ WindNinja и НЕ доказанный расчёт аэродинамического следа зданий. Добавлены bounded compare API и отдельный экран /drift-engine с общей шкалой кг/м² и research_unvalidated. Сравнивается legacy dynamic SnowState; исходная эмпирическая карта CitySnow сохранена, но не считается тем же самым результатом. Автоматический запуск тяжёлого CFD из HTTP отсутствует.

Сохранённые Copernicus DSM и OSM использованы без погодных запросов. 21 опыт проверяет flat/real/reverse/no-buildings/fresh/old-snow/feedback на трёх сетках. Массовый остаток нулевой. Это сценарная численная проверка, не уличная точность. Отдельно переиспользована локальная квартальная постановка старого исследования и реально запущен OpenFOAM v2512 simpleFoam: 9501 ячейка/40 итераций и 194581 ячейка/360 итераций. Получены U,p,k,epsilon,nut и журналы. Дорогой расчёт относится к воздуху, не снежной фазе. driftScalarDyFoam upstream SHA 6dd2fe97fe12741aa18d317b46b596880d77702f скомпилирован на v2512; учебный уменьшенный runtime успешно дошёл до 10000, сохранены поля и изменяемая сетка. Это execution smoke без доказанного CFD snow mass balance; на Камчатку модель ещё не перенесена.
