# Передача следующей сессии
Updated: 2026-11-23 · Asia/Kamchatka (UTC+12)

## Активное поручение

Пользователь попросил продолжить раздел «Kamchatka Drift Engine: сделано и осталось».
Выбран единственный активный DRIFT-003. Выполнен следующий атомарный этап:
временная CFD снежная фаза на геометрии квартала, ограниченный снегозапас и
независимая проверка полного bed/air/boundary бюджета. Это продолжение кода
955f048/cda7572, а не повтор выполненного static RANS coupling.

## Проверенный результат и источники

Основной источник — `docs/drift-engine/CFD_SNOW_CASE.md` в KamDispatch. Собственный
GPL-3.0-or-later solver `cfd/snowSolver/kamchatkaSnowFoam.C` собран и реально
выполнен под OpenFOAM v2512. Размер воздушной сетки — 194581 ячейка; общий
scene SHA b5237a92e4695c7de892cb96cb688beb36886db4fc20843bba0b920f5cdc36f1.
RANS восстановлен на coarse mesh, checkMesh OK, сохранён настоящий face phi.
Новый расчёт использует замороженные U/nut/phi и неподвижную сетку. Эрозия и
осаждение — явные сценарные замыкания, не калибровка по полевым наблюдениям.

Пять сценариев по пять секунд: nominal, half-step, no-erosion, depletion и
boundary-pulse; всего 300 временных шагов. Максимальный модуль остатка
3.074e-8 kg; отрицательных концентраций и запасов нет. В nominal eroded=11.571523,
deposited=4.608691, suspended=6.962832 kg. Граничный контроль вынес 1437.085014 kg
из явно заданного начального воздушного импульса. dt/2 дал 0.355654% относительной
L1 разности воздушных масс; это одна чувствительность, не доказанная сходимость.
Суммарная эрозия стресс-теста может превышать начальный запас из-за повторного
переноса ранее осевшей массы; каждый отдельный шаг ограничен запасом донора.

Журналы, таблицы каждого шага, summaries, хеши и PNG сохранены в
`docs/drift-engine/cfd/snow-evidence-v1`. Полные сетки/поля локально в
`/private/tmp/kamchatka-snow-runtime/verified-matrix`; временный каталог недолговечен.
Offline replay доступен без Docker. 100 city_sim tests и 5 core прошли; четыре
новых tests проверяют evidence, нулевой контроль и обнаружение пропущенного выноса.
PNG осмотрен. Переносимый образ и тяжёлый runtime CI пока не подтверждены.

## Checkout и параллельная работа

Продолжать CFD в `/private/tmp/kamdispatch-cfd-snow`, feature/kamchatka-drift-engine,
код 514f940 от опубликованного cda7572. Публикационный checkpoint будет потомком
этого SHA, поэтому сохранённая Git metadata описывает проверенную историческую
точку. Свежий статус PR/CI проверять отдельно после публикации.

Общий `/private/tmp/kamdispatch-city-sim-upload` сохранён: там параллельный
неопубликованный дорожный 2b91d35 и исходный локальный CFD 716351b. CFD cherry-pick
в отдельный checkout исключает случайный push дорожного коммита. Не сбрасывать
и не переписывать общий checkout; его дальнейшую синхронизацию делать с учётом
обеих историй. Предыдущий HANDOFF сохранён рядом в archive — там дорожный проект,
ROADS-007 и ROADS-008…015, которые этим поручением не закрывались.

## Следующие шаги и ограничения

1. Увеличить горизонт, проверить несколько dt и пространственных сеток на одинаковой
области/массе. Учитывать реальную численную схему и чувствительность замыкания.
2. Замкнуть snow geometry → mesh → новый воздух с контролем качества сетки.
3. Проверенный переносимый CFD-образ, отдельный тяжёлый CI и независимые замеры.

Начальная масса передаётся напрямую в kg из сцены: расчёт через округлённые грани
дал сдвиг 0.006293 kg и был исправлен. Точность линейного решения усилена до 1e-14
для стресс-теста без ослабления допуска бюджета. HTTP/API не менялись; снег крыш,
перехват фасадами и геометрический feedback не моделируются. Полевая точность,
измеренный DTM и эксплуатационная пригодность unknown. PR не сливать самостоятельно.
