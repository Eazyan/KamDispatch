Сверь git status, ветку/SHA, изменённые файлы и результаты команд. Обнови docs/agent-memory/STATE.md, TASKS.md, HANDOFF.md; дополни LOG.md, не переписывая прежние записи. Укажи дату Asia/Kamchatka, ошибки/успехи, незапущенные проверки, точные пути и 1–3 следующих шага. HANDOFF: 300–800 слов.

Новые выводы в KNOWLEDGE_BASE.md — только с датой, источником и статусом. Неизвестное — unknown, недоступная задача — blocked с условием разблокировки. Не открывай done без регрессии. Противоречия сохраняй в CLAIMS.md для ручной проверки.

После смысловых правок: `python3 scripts/agent_memory/memory.py checkpoint`, затем `python3 scripts/agent_memory/verify.py`. После новых правок повтори snapshot. Он не заменяет handoff и не доказывает точность модели. Не делай скрытых коммитов и бесконечных повторов; после трёх одинаковых ошибок запиши blocker.
