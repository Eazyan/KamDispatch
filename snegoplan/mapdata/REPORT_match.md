**Только локальные файлы, сеть не использовалась.** `mapprep/out/graph_v3.json` — только чтение.

## Метод

- **Нормализация имён:** lowercase, ё→е, раскрытие аббревиатур (ул/просп/пер/б-р/наб/ш/пл), удаление
  пунктуации; гибкое совпадение пробелов/дефисов («Северо- Восточное» = «Северо-Восточное»).
  Алиасы из 328 имён v3: полные формы + bare-формы (638 regex-алиасов); 7 коллизионных bare
  (Циолковского, Рыбаков, Дзержинского, Алтайская, Зелёная, Лесная, Спортивная) разрешаются
  только по полной форме; регистровые дубли v3 («Проспект Рыбаков»/«проспект Рыбаков») объединяются.
  Имена-гомонимы типа «Набережная улица» (bare пустой) матчатся по токенам полной формы.
- **Геометрия:** снап точки на ближайший сегмент ребра (сегментная сетка 75 м); пересечение улиц =
  середина ближайших точек их сегментов (порог 80 м); плечо у перекрёстка = пара edge+reverse_edge
  v3, с квалификатором «на север/юг/...» — по азимуту от перекрёстка.
- **Пороги:** улица ≤50 м, светофор/точка интенсивности ≤40 м (больше — не matched/high);
  fuzzy (difflib ≥0.8) — только fallback, confidence ≤ medium.
- **Дома по номерам** геокодированы через `residential.csv` (точный номер, fallback — числовая часть).
- **Светофоры:** пул для сверки — все 96 узлов OSM с `highway=traffic_signals` (95) или явным ключом
  `traffic_signals` (26, из них 1 пешеходный без highway); в выходе по ТЗ — 26 узлов с явным ключом.
  Дедуп КСОДД: кластеры ≤25 м, представитель (геом пересечения > точный дом > номер по части),
  остальные `ambiguous` со ссылкой на кластер. Привязка к OSM — one-to-one, жадно по дистанции ≤40 м.
  Колонка `addr_check` = расстояние до ближайшего узла v3 (junction/traffic_signals); >40 м —
  confidence не выше medium.
- **POI:** критичные = `amenity=hospital/clinic` → hospital, `office=government` → government,
  `school/kindergarten/college/university` → school (остальные 1949 attractor'ов — только статистика).
  Дедуп ≤75 м внутри уровня, представитель — ближайший к ребру. **`critical_access` и `bus_route_near`
  (флаг bus_route ближайшего ребра) хранятся отдельно и нигде не смешиваются с категорией/полосами дорог.**
- Ручной синоним (1 шт., зафиксирован в rationale строк): `Ул. Академика Заварицкого` (КСОДД) =
  `переулок имени Заварицкого А. Н.` (v3) — совпадение подтверждено геометрией перекрёстка
  (геом d=4 м у точки 38).

## Sampled QA (ручная, по OSM-геометрии)

Проверено **59 строк** стратифицированно: все 30 high-confidence светофоров + 8 lanes + 8 intensity
+ 7 road_categories + 4 POI hospital + 5 buildings (скрипт `scripts/qa_context.py`, дампы
`data/qa_sample_tl_high.json`, `data/qa_sample_other.json`).

- **Светофоры high (30/30):** каждая точка лежит в 0–7 м от обеих улиц адреса и в 0–17 м от узла
  kind=traffic_signals. **Ложных high-confidence: 0.** Все 30 подтверждены.
- **lanes/intensity (16):** перекрёстки и плечи (в т.ч. азимут «на север/юг») совпадают с геометрией.
- **POI hospital (4):** больницы лежат у названных улиц; снап 11–34 м (дворовые владения).
- **buildings (5):** 3 matched — у адресной улицы (у 1 здания «Горная, 8» снап на дворовый проезд
  6 м vs Горная 63 м — норма для двора, addr не переносится в граф); 2 unmatched — изолированы
  (>50 м до любого ребра, подтверждено замером).
- **Находки с понижением:** ложных high нет; два правила ужесточены в ходе QA:
  house-геокод по числовой части без OSM-пары → ambiguous (не matched); addr_check >40 м →
  conf ≤ medium.
