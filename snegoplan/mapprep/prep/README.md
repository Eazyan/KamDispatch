# Подготовка карты Снегоплана

Запуск (из корня mapprep): `python3 prep/run_prep.py && python3 prep/build_check_map.py`
Опционально (Windows, интернет): `python scripts\fetch_bus_routes.py`, затем повторить запуск.

## Сопоставление с OSM
В graph.json нет osmid; узлы сопоставляются с graphml по координатам (1:1, 6 знаков), ребро (u,v) - с
(u,v)/(v,u) в graphml, при параллельных - по минимальной средней дистанции вершин геометрии.
Результат: 1700/1700 рёбер, расстояние 0 м (геометрия идентична).
Недостающий тег берётся у парного обратного ребра (случаев не было).

## Полосы, ширина
- lanes: "2;3" -> max; список путей -> самое частое, при ничьей max. Нет тега -> по умолчанию
  (primary/secondary/trunk: 4 для двусторонней, 2 для односторонней; tertiary/residential/unclassified 2;
  living_street/service 1). lanes_source = osm | default.
- width: "7", "7 m", "7,5" -> метры. maxspeed: число; RU:urban=60, RU:rural=90.
- width_m = OSM width, иначе lanes * lane_w + 0.5, где lane_w = 3.5 (trunk/primary/secondary), 3.25 (tertiary), 3.0 (прочие).
  width_source = osm_width | lanes (lanes из OSM) | default (lanes по умолчанию).
- width_m - полная ширина проезжей части; width_dir_m = width_m/2 для двусторонних, иначе width_m.

## Приоритет
1: trunk/primary/secondary (+_link) или ребро на автобусном маршруте (out/bus_routes.json: way_ids
   сопоставляются с osm_way_ids ребра; `street_names` - ручной список названий);
2: tertiary/residential/unclassified с названием; 3: living_street/service или без названия.
Флаг bus_route хранится на ребре.

## Зоны (9)
1. Взвешенный k-means по узлам (км, вес узла = половина длины инцидентных улиц), старт по квантилям вдоль главной оси.
2. Ремонт связности (неориентированный граф): лишние компоненты зоны уходят к соседней зоне с наибольшим числом связей.
3. Локальный поиск: перенос граничных узлов, если зона-источник остаётся связной и снижается
   cost = 2000 * sum((L_k/mean-1)^2) + 20 * (сумма квадратов расстояний до центроидов / (N * площадь/9)),
   L_k считается с учётом правила владения рёбрами.
4. Нумерация зон с севера на юг (по центроиду). Владение: ребро - в зону u, если оба конца в одной зоне;
   межзонные улицы (обе направления вместе) - зоне с меньшей текущей нагрузкой (ничья - меньший номер);
   обратное ребро всегда в той же зоне. Нагрузка = требуемые км (все рёбра required).
Зона 1 (северо-запад) смежна только с зоной 3 и небольшая: её граничные рёбра уже отданы ей.
