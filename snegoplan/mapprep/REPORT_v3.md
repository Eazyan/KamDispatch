# Отчёт graph_v3 (пересборка графа из свежего OSM)

Дата: 2026-11-22. Скрипт: `prep/build_v3.py` (импортирует парсеры из `prep/run_prep.py`, тот не менялся).
Вход: `mapdata/data/osm_petropavlovsk.json` (Overpass out geom, 13.7 МБ).

## Результат против v2

| | v2 | v3 |
|---|---|---|
| узлов | 684 | 9 620 |
| рёбер | 1 700 | 23 172 |
| сумма км (оба направления) | 289.7 | 2 498.0 |

Рост объясняется покрытием: v3 построен по всему городу из свежей выгрузки (6 193 way прошли фильтр
highway из 10 333), v2 — по ограниченному graph.json. Схема узла/ребра — как в v2 плюс `*_source`
и `elevation_source` у узлов.

## Проверки (встроены в скрипт, все прошли)

- Граф сильно связный: из 48 сильно связных компонент оставлена крупнейшая (выкинуто 716 узлов
  мелких обособленных фрагментов — дворовые петли/тупики-отрезки вне основной сети).
- 9 зон, каждая связна; нумерация с севера на юг; обратное ребро всегда в той же зоне.
- У всех 23 172 рёбер все поля схемы и `*_source`.

## Выходы

- `out/graph_v3.json` (15.3 МБ), `out/zones_v3.json`, `out/prep_stats_v3.json`.
- `out/check_map_v3.html` (3.3 МБ) — `prep/build_check_map.py` параметризован путями
  (argv: graph, zones, out.html), старый вызов без аргументов работает как раньше
  (`out/check_map.html` для v2 пересобран тем же кодом, `graph_v2.json` не изменялся);
  в шаблон добавлен слой «Светофоры» и подписи источников из данных.
- `out/edge_weights.csv` (23 172 строки) и `out/mean_weights.json` (50 групп zone|highway):
  v_work = min(20, базовая): trunk/primary/secondary 20, tertiary 15, прочее 10, service 10;
  v_dead: trunk/primary/secondary 40, tertiary 30, прочее 25, min(maxspeed); service 10.

## Пропущено (причина)

Пункты TASK 9–12 (значения КСОДД lanes/категории, tl_cycle_s из КСОДД, остановки, POI): в
`mapdata/data/` отсутствуют `ksodd_street_match.csv`, `bus_stops.csv`, `traffic_lights_match.csv`,
`poi.csv` и `ksodd_tables/` — задача mapdata (TASK_poi_ksodd.md) не выполнена. Место зарезервировано:
`_source` принимают `ksodd`, на светофорных узлах предусмотрены `tl_cycle_s/tl_cycle_source`.
Значений КСОДД в графе: 0. В `edge_weights.csv` колонки tl_delay_s/bus_stop/near_poi пока пустые
(bus_stop флагирован только по автобусным маршрутам relation), `out/poi_v3.json` не создан.

## Замечания

- Односторонних рёбер мало: 206 (в основном _link и service) — остальное двусторонние пары.
- Зона 3 (север, аэропорт) почти без имёнованных дорог: П2 = 0 — закономерно для выгрузки.
- `task_id` у рёбер v3 = null (в v2 был номер задачи CARP из старой нарезки); уличный id =
  `S-<min(u,v)>-<max(u,v)>-<key>`.
